**idTip WotLK**, ранее известный как **SpellAndItemID**, — это лёгкий аддон для World of Warcraft, который добавляет полезную техническую информацию непосредственно во внутриигровые подсказки.

Разработан для **World of Warcraft 3.3.5a**.

Текущая версия: **1.8** · Дата обновления: **2026-11-01**.

</div>

## Возможности

Аддон автоматически дополняет поддерживаемые игровые подсказки технической информацией, полезной разработчикам аддонов, администраторам серверов, создателям контента и опытным игрокам.

Аддон может отображать:

* **ID заклинания** — идентификатор и, если доступен, ранг заклинания, способности, положительного или отрицательного эффекта.
* **ID рецепта** — идентификатор ремесленного заклинания в ссылках и подсказках профессии.
* **ID результата** — идентификатор создаваемого предмета, если рецепт его создаёт.
* **Наложено** — имя персонажа или существа, наложившего эффект.
* **Вы** — отмечает эффекты, наложенные текущим персонажем.
* **ID предмета** — идентификатор предмета.
* **ID комплекта** — идентификатор комплекта, к которому относится предмет.
* **ID зачарования** — идентификатор постоянного зачарования предмета.
* **ID вставленных камней** — идентификаторы и названия вставленных камней с указанием сокета, если доступны ссылки на камни.
* **ID НИП** — идентификатор существа или NPC.
* **ID задания** — идентификатор задания в ссылке, при наведении на запись журнала и в сведениях о выбранном задании.
* **ID достижения** — идентификатор достижения.
* **ID критерия достижения** — идентификатор критерия достижения.
* **ID записи символа** — идентификатор записи в GlyphProperties.dbc.
* **ID заклинания символа** — идентификатор связанного с символом заклинания.
* **Иконка** — технический путь к используемой иконке.

В подсказках профессий совпадающие ID рецепта и заклинания, а также результата и предмета показываются только один раз.

ID комплектов определяются по встроенным данным WotLK и не требуют нестандартного API клиента или внешнего DBC-файла во время игры.

Данные с названиями зачарований сохранены в `idTip/Data`, но аддон их не загружает и не показывает в подсказках.

## Пример подсказки

В зависимости от выбранного объекта, заклинания или элемента интерфейса аддон может добавлять следующие строки:

```text
ID заклинания: 12345 (Ранг 1)
ID рецепта: 2657
ID результата: 2840
Наложено: PlayerName (Вы)
ID предмета: 51280
ID комплекта: 883
ID зачарования: 3817
ID сокета 1: Название камня                   40155
ID НИП: 36597
ID задания: 24545
ID достижения: 4530
ID критерия достижения: 12345
ID записи символа: 361
ID заклинания символа: 56829
Иконка: INV_Gauntlets_90Black
```

Добавленная информация выделяется цветом, благодаря чему разные типы идентификаторов можно быстро отличить друг от друга.

## Поддерживаемые типы подсказок

idTip WotLK работает со многими стандартными подсказками World of Warcraft, включая:

* заклинания и способности;
* положительные и отрицательные эффекты;
* предметы в сумках;
* экипировку;
* постоянные зачарования и вставленные камни в экипировке;
* ссылки на предметы;
* рецепты профессий и создаваемые предметы;
* существ и NPC;
* задания;
* достижения;
* критерии достижений;
* символы;
* иконки.

Доступность конкретной информации зависит от типа подсказки и данных, предоставляемых игровым клиентом.

Встроенные соответствия предметов и комплектов охватывают поставляемые данные WotLK. Для пользовательских предметов или изменённых комплектов необходимо обновить [`Data/ItemSetData.lua`](idTip/Data/ItemSetData.lua).

## Установка

1. Загрузите последнюю версию аддона со страницы [Releases](https://github.com/darhanger/idTip-WotLK/releases).
2. Распакуйте загруженный архив.
3. Переместите папку аддона в:

```text
World of Warcraft\Interface\AddOns\
```

4. Убедитесь, что структура папок выглядит следующим образом:

```text
World of Warcraft
└── Interface
    └── AddOns
        └── idTip
            ├── Data
            │   ├── GlyphData.lua
            │   └── ItemSetData.lua
            ├── Core.lua
            ├── Localization.lua
            ├── Options.lua
            └── idTip.toc
```

5. Перезапустите игровой клиент.

## Совместимость

* World of Warcraft **3.3.5a**
* Lua **5.1**
* Стандартный интерфейс Blizzard
* Большинство аддонов, изменяющих игровые подсказки

Совместимость с сильно модифицированными игровыми клиентами или аддонами, полностью заменяющими стандартные подсказки, может отличаться.

Встроенные соответствия ID и названий корректны для BlizzLike-серверов с данными 3.3.5a. На серверах с изменёнными предметами, зачарованиями и другими данными название или соответствие ID может отличаться от серверного.

## Использование

Аддон начинает работать сразу после установки. ID постоянных зачарований и вставленных камней по умолчанию отключены; их можно включить в настройках.

Наведите курсор на поддерживаемое заклинание, предмет, NPC, задание, достижение или другой элемент интерфейса. Соответствующая техническая информация будет автоматически добавлена в подсказку.

## Настройка

Откройте настройки интерфейса Blizzard и выберите **idTip WotLK** → **Настройки**. Здесь можно включать и отключать ID заклинаний, наложивших эффект персонажей, ID предметов, постоянных зачарований, вставленных камней и комплектов, NPC, заданий, достижений и критериев, символов, рецептов и пути к иконкам. Настройка рецептов управляет одновременно ID рецепта и результата. Строка ID зачарования не включает временные зачарования.

Чтобы восстановить стандартные значения, нажмите отдельную кнопку **Сброс**. Сброс применяется кнопкой **ОК** и отменяется кнопкой **Отмена**. Стандартное действие Blizzard **По умолчанию** также поддерживается.

## Для чего нужен idTip WotLK?

Ручной поиск игровых идентификаторов может занимать много времени, особенно при разработке аддонов, настройке базы данных или отладке серверного контента.

idTip WotLK отображает необходимые идентификаторы непосредственно в игровом клиенте без использования сторонних сайтов, команд или ручного поиска по базе данных.

Аддон может быть полезен для:

* разработки аддонов;
* написания Lua-скриптов;
* разработки на TrinityCore и AzerothCore;
* редактирования базы данных;
* отладки заданий и достижений;
* настройки заклинаний и эффектов;
* определения идентификаторов NPC, предметов и комплектов;
* тестирования пользовательского серверного контента.
